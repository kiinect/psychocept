# UI + look plan (supersedes 08b). Goal: feel and flow of Bloons TD 6, all art original.
Screen flow: Boot/splash (logo card, "tap to start", loads atlas) -> MAIN MENU (big Play, Heroes, Powers, Achievements-lite, Settings, Profile/rank bar with XP + Monkey Money) -> MAP SELECT (paged horizontal carousel of map cards by tier tabs Beginner/Intermediate/Advanced/Expert, big thumbnails, best-medal badges, back button) -> DIFFICULTY (Easy/Medium/Hard cards, Impoppable) -> MODE select (per difficulty list, 3-4 mode cards, Sandbox) -> hero pick (carousel of heroes with portrait, locked/unlocked) -> IN-GAME -> pause menu (Resume, Restart, Home, Settings) -> Victory / Defeat screens (rewards: XP, Monkey Money, rank-up toast) -> back to menu.
In-game HUD (match BTD6 layout): top-left: lives (heart), cash (coin) pills with big numerals; top-right: round counter "Round 12/60", settings gear, pause; bottom-right: big round PLAY button with fast-forward toggle (x1/x2/x3 chevrons), autoplay toggle; RIGHT SIDEBAR (collapsible, opens with a tab): tower shop in a 2-column grid of tower icons (sprites) with price badges, 4 category tabs (Primary/Military/Magic/Support) + Hero + Powers, disabled/red price when unaffordable, drag-to-place with ghost + range ring (red if invalid); selected tower -> UPGRADE PANEL on the opposite side of the screen from the tower: tower portrait, name, 3 upgrade path columns with tier pips, next-upgrade card with icon/name/cost/description, owned-tier list, sell button with refund, targeting arrows (First/Last/Close/Strong), ability button, XP/pops count. Floating pop numbers, cash drift, round-end banner. Hotkeys (Q W E R... / space / F) like the original.
Look: bright saturated cartoon, thick dark outlines, soft shadows under everything, wooden/blue glossy panels (src/art/ui textures), chunky rounded fonts (system font stack fallback; embed none external), buttons squish on press, screen transitions (fade/slide), panel pop-in tweens.
Map art (original, code-drawn, must look rich): per-map painterly base (multi-octave value-noise grass in 3 greens with lighter patches + subtle brush strokes), flowers/grass tufts, stone-tile path with lighter inner and darker rounded outline plus pebble border, trees as layered clumps with soft drop shadows and highlights, rocks/logs/ponds with ripples/lily pads, water with animated foam/shimmer, themed per map (town cobbles, scrapyard scrap, cornfield rows, castle stones, ravine rock), no-build objects visibly match their blocking circles, vignette. 960x540 world drawn at devicePixelRatio and cached to a texture once per map.
Integration: Pixi stage uses src/art atlas for towers (rotate to target, attack recoil), bloons (sprites, shine), projectiles, pop fx; pool + batch for 1000+ bloons at 60fps. DOM/CSS overlays for panels (keep accessible, keyboard focus), responsive: phone/tablet landscape layout switches sidebar to bottom sheet.

Deployment note (user, 2026-10-22): hosted on the user's own site, so multi-file dist/ is fine and external files, fonts, workers and fetch of own static files are allowed. `npm run build:single` (one inlined index.html) stays available as an optional build, no longer required.
